# Teclado e mouse

[← Início do wiki](Home.md) · [English](../Keyboard-and-mouse.md)

## Em qualquer lugar do editor

| Teclas | O que fazem |
| --- | --- |
| `Ctrl+N` | Pet novo (o assistente ou o modelo) |
| `Ctrl+O` | Abrir um `animations.xml` |
| `Ctrl+S` | Salvar |
| `Ctrl+Shift+S` | Salvar como |
| `Ctrl+Z` | Desfazer (numa caixa de texto: desfaz o que foi digitado) |
| `Ctrl+Y` | Refazer |
| `F5` | [Testar no desktop](Testar-no-desktop.md) |

## Listas

| Teclas | O que fazem |
| --- | --- |
| `Delete` | Tira a animação, entrada, janela filha ou som escolhido (para animações, pergunta antes) |
| `Esc` na caixa de busca | Limpa a busca |

## Prévia

Quando o cursor não está numa caixa de texto:

| Teclas | O que fazem |
| --- | --- |
| `Espaço` | Pausar / continuar |
| `→` | Um passo |
| `R` | Do começo |

## Tour

`Enter` ou `→` continua, `Esc` fecha.

## Editor de pixels

| Teclas / mouse | O que fazem |
| --- | --- |
| Botão esquerdo | Pinta |
| Botão direito | Apaga |
| `Ctrl+Z` | Desfazer |

## Mouse

| Onde | O que faz |
| --- | --- |
| Pet na prévia | Arraste para mover; solte devagar para ele cair, jogue para arremessar |
| Quadro na faixa de uma animação | Arraste para mudar a ordem; × tira; botão direito abre um menu |
| Quadro da folha de sprites | Clique para pôr na animação |
| Divisórias da página Animações | Arraste para mudar o tamanho das partes |
| Mapa das animações | Arraste para mover, rodinha para aproximar, clique num cartão para destacar, duplo clique para abrir |
| Arquivos do Explorador | Solte na janela ([A janela](A-janela.md#soltar-arquivos-na-janela)) |
