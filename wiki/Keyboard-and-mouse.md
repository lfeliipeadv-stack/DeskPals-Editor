# Keyboard and mouse

[← Wiki home](Home.md) · [Português](pt-BR/Teclado-e-mouse.md)

## Anywhere in the editor

| Keys | What they do |
| --- | --- |
| `Ctrl+N` | New pet (the assistant or the model) |
| `Ctrl+O` | Open an `animations.xml` |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+Z` | Undo (in a text box: undo the typing) |
| `Ctrl+Y` | Redo |
| `F5` | [Test on the desktop](Test-on-the-desktop.md) |

## Lists

| Keys | What they do |
| --- | --- |
| `Delete` | Removes the chosen animation, entrance, child window or sound (it asks first for animations) |
| `Esc` in the search box | Clears the search |

## Preview

When the cursor is not in a text box:

| Keys | What they do |
| --- | --- |
| `Space` | Pause / continue |
| `→` | One step |
| `R` | From the start |

## Tour

`Enter` or `→` goes on, `Esc` closes it.

## Pixel editor

| Keys / mouse | What they do |
| --- | --- |
| Left button | Paints |
| Right button | Erases |
| `Ctrl+Z` | Undo |

## Mouse

| Where | What it does |
| --- | --- |
| Pet in the preview | Drag to move it; let go slowly to drop it, fling it to throw it |
| Frame in an animation's strip | Drag to change the order; × removes; right button opens a menu |
| Frame of the sprite sheet | Click to add it to the animation |
| Dividers of the Animations page | Drag to change the size of the parts |
| Animation map | Drag to move, wheel to zoom, click a card to highlight, double-click to open |
| Files from the Explorer | Drop them on the window ([The window](The-window.md#dropping-files-on-the-window)) |
